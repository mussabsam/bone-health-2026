# كتيب صحة العظام المتجاوب · 2026

نسخة عربية من عشر رسائل مع صور الحملة المعتمدة. يدعم الهاتف والشاشات الكبيرة، التباين العالي، تكبير النص، التنقل بلوحة المفاتيح، وقارئات الشاشة. الاستماع يعتمد على وجود صوت عربي في نظام الجهاز أو المتصفح؛ لا يُشغَّل تلقائيًا.

## النشر على GitHub Pages
من Settings → Pages اختر Deploy from a branch، ثم main والمجلد /docs واحفظ. إذا لم يكن النشر متاحًا للمستودع الخاص، استخدم خطة تدعم Pages للمستودعات الخاصة أو انشر هذه الملفات في مستودع عام مخصص بعد مراجعتها. لا تغيّر خصوصية المستودع الحالي دون مراجعة محتوياته.

## التشغيل محليًا
افتح docs/index.html أو شغّل خادم ملفات ثابتًا من docs. جميع الصور والخطوط ضمن assets؛ لا توجد مكتبات خارجية أو حسابات أو تحليلات تتبع. تُحفظ تفضيلات العرض في المتصفح فقط.

## الاختبارات
التحقق من التخطيط عند عرض 320 و390 و1280 بكسل، تكبير النص، التباين، التنقل، الصوت المتاح/غير المتاح، وفحص آلي للوصول. الاختبارات الآلية لا تغني عن تجربة مستخدمين مع تقنياتهم المساعدة.
